🌾 SMART-SURJAN

Solusi Modernisasi Adaptif Sistem Surjan untuk Ketahanan Pangan Indonesia

Lihat di GitHub

📖 Tentang Proyek

SMART-SURJAN adalah model modernisasi adaptif untuk sistem pertanian surjan di lahan basah Indonesia. Proyek ini menggabungkan pengetahuan lokal (termasuk Pranata Mangsa) dengan teknologi monitoring air digital sederhana untuk meningkatkan ketahanan pangan menghadapi perubahan iklim.

🎯 Fitur Utama

💧 Monitoring Air Real-Time

Sensor IoT mengukur ketinggian air dan salinitas secara berkala.

📱 Notifikasi SMS/WhatsApp

Petani menerima peringatan langsung di ponsel mereka.

🗓️ Integrasi Pranata Mangsa

Jadwal pasang surut terpadu dengan kalender tradisional Jawa.

🔊 Petunjuk Suara

Fitur audio untuk petani dengan literasi rendah.

👥 Keputusan Musyawarah

Tetap berbasis kelompok tani, bukan otomatis sepenuhnya.

🌱 Diversifikasi Tanaman

Rekomendasi komoditas sesuai kondisi air dan salinitas.

📱 Purwarupa Antarmuka

🏗️ Arsitektur Sistem

Sensor (IoT) → Server (Cloud) → Petani (Mobile)

  • Sensor: Ultrasonik (ketinggian air) + Konduktivitas (salinitas)
  • Koneksi: LoRa / WiFi
  • Server: Cloud-based (Firebase / AWS)
  • Antarmuka: Aplikasi mobile + SMS/WhatsApp
